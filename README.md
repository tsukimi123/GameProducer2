# Game Producer 2｜雙人合作動作解謎

《Game Producer 2》是由三人團隊製作的 PC 雙人連線遊戲。兩名玩家分別扮演「美術」與「程式」，一人用畫筆在關卡裡生成物件，另一人操控場景中的物件，兩人一起通過懸吊平台與升降機關。

[觀看宣傳影片](https://tsukimi123.github.io/Project/GameProducer2/video/gameproducer2-promo.mp4) · [前往作品展示頁](https://tsukimi123.github.io/GameProducer2.html)

[![兩名角色合作通過平台機關的遊戲畫面](https://tsukimi123.github.io/Project/GameProducer2/hero-gameplay.webp)](https://tsukimi123.github.io/Project/GameProducer2/video/hero-coop-loop.mp4)

## 角色與玩法

- **美術**在場景中畫出路徑，讓筆畫變成可以互動的物件。[觀看繪製片段](https://tsukimi123.github.io/Project/GameProducer2/video/artist-ability-loop.mp4)
- **程式**可以拖曳或投擲場景中的物件，也能發射縮放彈，將命中的特定物件放大。[觀看物件操作片段](https://tsukimi123.github.io/Project/GameProducer2/video/programmer-control-loop.mp4)

- 開發工具：Unity 2019.4.41f2、C#、Photon PUN
